# Kelmscott

![Kelmscott Press](kelmscott-press.jpg)

Ce référentiel doit être cloné sur la machine de compilation.

## Installation

```bash
sudo apt install git
git clone https://github.com/osunyorg/compilation.git
cd compilation
bin/setup
bin/run
```

## Mise à jour

```bash
cd compilation
git pull
cd ..
compilation/bin/update
compilation/bin/run
```
