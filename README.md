# Kelmscott

![Kelmscott Press](kelmscott-press.jpg)

Ce référentiel doit être cloné sur la machine de compilation.

## Installation

```bash
sudo apt update
sudo apt install -y git
git clone https://github.com/osunyorg/compilation.git
cd compilation
bin/setup
bin/run
```

## Mise à jour

```bash
cd compilation
git pull
bin/update
bin/run
```
